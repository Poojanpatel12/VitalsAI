First Aid Guide

Heart attack / chest pain
  1. Sit or lie down and stay calm.
  2. Loosen tight clothing.
  3. Do not eat or drink.
  4. Call 108 immediately if pain is severe, sweating, or breathlessness occurs.
Stroke FAST check
  1. Face drooping?
  2. Arm weakness?
  3. Speech slurred?
  4. If yes to any, call 108 immediately.
Severe bleeding
  1. Apply firm pressure with clean cloth.
  2. Raise injured part if possible.
  3. Do not remove deep objects.
  4. Call 108 for heavy bleeding.
Burn injury
  1. Cool under running water for 10-20 minutes.
  2. Remove jewelry near burn.
  3. Cover with clean cloth.
  4. Do not use ice, butter, or toothpaste.
Choking
  1. Encourage coughing if able.
  2. Give 5 back blows.
  3. Give 5 abdominal thrusts.
  4. If unconscious, call 108 and start CPR if trained.
